# Higgsfield CLI

For every `higgsfield`, `higgs`, or `hf` command in this repository, set both environment variables below in the command environment:

```sh
HIGGSFIELD_CREDENTIALS_PATH=/Users/shreychaudhary/.higgsfield/credentials.json
HIGGSFIELD_CONFIG_PATH=/Users/shreychaudhary/.higgsfield/config.json
```

Never read, print, copy, or commit the contents of the credentials file. Image and video generation consumes Higgsfield credits, so confirm the requested output and cost when the applicable Higgsfield skill requires it.
